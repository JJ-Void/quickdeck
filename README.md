# QuickDeck

Короче на вайбкодил программку, которая лично мне, очень упрощает работу, что то панели быстрого доступа.
вполне вероятно, что все очень криво сделано, так как первоначальная задача упростить себе жизнь, а не оптимизация. Надеюсь, что кому-нибудь данная программа упростит рутину. В качестве примера областей применения, загрузил два готовых персета - один для работы, другой для домашнего использования. Остальная работа ограничивается только вашей фантазией.

А теперь комменты от нейронки:

**Зажал Alt, крутанул колесо — нужный документ, папка или готовый текст уже открыт.**

Лаунчер для тех, кто каждый день лезет в одни и те же файлы, шаблоны и ссылки.
Без облака, без аккаунтов, без интернета.

## Зачем

Менеджер по продажам за день двадцать раз открывает одну и ту же папку с договорами,
копирует одни и те же реквизиты, ищет шаблон письма. Каждый раз — десяток кликов
по проводнику и почте. QuickDeck убирает эту дорогу: всё, к чему ты возвращаешься,
лежит на одном движении мыши.

## Как это работает

Зажми **Alt** и крути колесо — у края экрана разворачивается дуга с категориями.
Отпустил Alt — провалился внутрь, там тем же колесом выбираешь кнопку.
Левая кнопка мыши и Enter — вперёд, правая и Esc — назад.

| | |
|---|---|
| <img src="docs/wheel-categories.png" width="400"> | <img src="docs/wheel-home.png" width="400"> |
| Категории — первый уровень | Кнопки внутри категории |

Ещё два способа: **Ctrl+Space** — поиск по всем кнопкам, когда их много;
маленькая ручка у края экрана — клик открывает колесо, а перетаскиванием
виджет переезжает к другому краю.

## Что умеют кнопки

| Тип | Что делает |
|---|---|
| **Открыть** | файл, папку, программу или ссылку — `C:\Работа\Объекты`, `steam://rungameid/570`, `https://crm...` |
| **Копировать текст** | реквизиты, подпись, готовое сообщение — клик, и оно в буфере |
| **Шаблон с подстановкой** | в тексте поля `{имя}`, `{объект}`, `{сумма}` — при клике спросит значения и покажет предпросмотр. `{дата}` и `{время}` подставляются сами |
| **Копия документа** | берёт `Договор.docx`, делает копию в рабочей папке под именем `Договор_2026-09-14_Иванов.docx` и открывает её |

Опция «вставлять сразу в активное окно» дожимает Ctrl+V — текст падает прямо в письмо.

## Установка

Скачай на странице [Releases](https://github.com/JJ-Void/quickdeck/releases/latest):

- **QuickDeck-Setup-x.x.x.exe** — обычный установщик (Inno Setup): мастер с выбором папки,
  ярлыки, автозапуск, удаление через «Установку и удаление программ».
  Прав администратора не требует.
- **QuickDeck-portable.zip** — распаковал и запустил `QuickDeck.exe`, ничего не устанавливается.

Антивирус может ругаться на неподписанный файл — типовое ложное срабатывание для программ
с глобальным хуком клавиатуры. Как это решается по-настоящему (подпись кода, перепроверка
у вендоров) — в [ANTIVIRUS.md](ANTIVIRUS.md).

## Наборы кнопок

Настроил один раз — можно раздать. В колесе: **Настройки → Наборы кнопок**.

В комплекте две заготовки: **«Дом»** (игры через Steam, YouTube, Twitch, мессенджеры,
музыка, системные папки) и **«Зам. директора»** (объекты, сметы, создание договора,
КС-2 и счёта из шаблонов, письма подрядчикам, банк-клиент).

Свой набор сохраняется в `*.qdeck.json` и загружается у коллеги одним окном —
получится общий корпоративный набор шаблонов. Личные настройки при этом не перетираются:
сторона экрана, масштаб и горячие клавиши у каждого свои.

## Сборка из исходников

```bat
git clone https://github.com/JJ-Void/quickdeck.git
cd quickdeck
build.bat            :: соберёт dist\QuickDeck\QuickDeck.exe
build-installer.bat  :: соберёт установщик локально (нужен Inno Setup 6)
```

Нужен Python 3.10+ с галкой «Add python.exe to PATH». Для запуска без сборки:
`pip install -r requirements.txt` и `python run.py`.

Локально Inno Setup ставить не обязательно: каждый push на `main` собирает программу
и установщик на GitHub Actions, где он уже есть, а по тегу `v*` выкладывает релиз.
Это и есть основной способ выпуска — файлы собираются на чистой машине из открытого кода.

## Под капотом

Python + PySide6, `pynput` для глобального хука Alt и колеса, PyInstaller для сборки.
Шрифт [Manrope](https://github.com/sharanda/manrope) (OFL), иконки [Lucide](https://lucide.dev) (ISC).
Технические заметки и объяснение решений — в [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
