# История версий

## 1.0.0

Первый публичный выпуск.

- Колесо-дуга у края экрана: Alt + колесо мыши, два уровня — категории и кнопки внутри.
- Четыре типа кнопок: открыть файл/папку/ссылку, копировать текст, шаблон с подстановкой
  полей, копия документа из шаблона с датой в имени.
- Быстрый поиск по всем кнопкам на Ctrl+Space.
- Ручка у края экрана: перетаскивается между левым и правым краем, клик открывает колесо.
- Наборы кнопок: две готовые заготовки, импорт, экспорт и удаление.
- Масштаб колеса 70–180 %, выбор края экрана, автозапуск с Windows.
- Установщик без прав администратора, портативный вариант архивом.
